AI Toolkit Enterprise

Type a request in plain language and the grid either changes the view (sort, filter, group) or answers an analytical question it computes over the data: min / max / median, averages by group, rankings ("who earns the most", "which department has the highest average salary"). The <apex-grid-ai> panel sends your prompt through grid.runPrompt(); changes offer a one-click Undo, Preview shows the plan first, and a badge names whoever handled it. This page runs entirely on the built-in deterministic rule engine: no API key, no network.

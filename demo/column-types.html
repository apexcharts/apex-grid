Built-in Column Types

All 13 types, split the way they behave. The first grid holds the seven value types, which carry the data's own meaning and are editable. The second holds the six presentation renderers, which draw a primitive value as a visual and are display only.

Value types

string, number, boolean, select, rating, date and image. Double-click any cell to see its type-specific editor.

Presentation renderers

avatar, badge, status, currency, progress and sparkline. These have no editor of their own, so the grid is read-only. Sorting still works, because it compares the stored values rather than what you see.
